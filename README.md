# Weirdest Job Title: Blind Judge Showdown

Entry for the [make.fun bounty "Weirdest Job Title: Blind Judge Showdown"](https://make.fun/bounty/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922) — one job title, the weirdest one we could think of, judged blind against the field.

## The entry

> **Senior Nap Tester for Luxury Mattress Showrooms**

A real-sounding job with one gloriously specific twist: getting paid to nap. 47 characters, inside the 1–60 gate.

## How it works

`main.ts` (Node 22, stdlib only, deterministic, offline) writes that single title to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), after validating it is 1–60 characters, trimmed, with no whitespace-only content and no control characters, and verifying the written file matches the title byte for byte.

```sh
node main.ts
cat "$MAKEFUN_OUTPUT_DIR/entry.txt"
```
